Project Engineering Highlights

  • Idempotent Recurring Billing: Utilizes PostgreSQL composite unique constraint (subscription_id, period_start) with ON CONFLICT DO NOTHING and per-subscription FOR UPDATE locks. Completely eliminates duplicate charges.
  • Server-Enforced State Machine: Moves strictly from Draft ➔ Quotation ➔ Confirmed ➔ Active ➔ Closed. Prohibits invalid state transitions with HTTP 409 Conflict.
  • Dynamic Variant Surcharges: Configurable variants like Brand = Odoo (+₹560) dynamically calculate total unit prices.
  • Automated Fiscal Rules: Redemptions, discounts (e.g. 10% off for 5+ seats), and tiered tax rates apply automatically upon billing run.
  • Emergent Paid Status: Invoices settle to 'Paid' automatically when remaining balance hits ₹0. Overpayment is strictly rejected.
  • Enterprise Scale: Queries over 5,000 subscriptions and ~12,000 invoices respond in 20–40ms using PostgreSQL analytical views.
