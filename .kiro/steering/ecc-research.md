# Deep Research

Adapted from ECC's `deep-research` skill ([affaan-m/ECC](https://github.com/affaan-m/ECC), MIT). Content was rephrased/condensed for compliance with licensing restrictions.

> Pull into chat with `#ecc-research` when you want a thorough, cited investigation.

## Workflow

1. **Clarify the goal** — learning, deciding, or writing? Any specific angle or depth? If the ask is "just research it," proceed with sensible defaults.
2. **Plan** — break the topic into 3-5 sub-questions.
3. **Search multi-source** — for each sub-question, run 2-3 keyword variations across the available web search tools. Aim for 15-30 unique sources. Prioritize academic/official/reputable news over blogs over forums.
4. **Deep-read** — fetch full content of 3-5 key sources; don't rely only on snippets.
5. **Synthesize** — write a structured report with inline citations.
6. **Deliver** — short topics inline; long reports as an executive summary + a saved file.

## Report structure

```markdown
# [Topic]: Research Report
*Generated: [date] | Sources: [N] | Confidence: [High/Medium/Low]*

## Executive Summary
## 1. [Theme] — findings with inline [Source](url) citations
## Key Takeaways
## Sources
## Methodology
```

## Quality rules

1. Every claim needs a source — no unsourced assertions.
2. Cross-reference; flag single-source claims as unverified.
3. Prefer sources from the last 12 months.
4. Acknowledge gaps; say "insufficient data found" rather than guessing.
5. Separate fact from inference — label estimates, projections, and opinions.
