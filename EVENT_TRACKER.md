## ✅ Action Checklist

### Pre-Event Preparation (Before Oct 30)
- [ ] Verify login access for all team members on the Odoo portal.
- [ ] Review official registration documentation and guidelines.
- [ ] Prepare development environments (Python/Odoo stack, PostgreSQL, Git, IDEs, Docker if required).
- [ ] Set up screen recording and presentation tools (e.g., OBS, Loom) for the final video demo.
- [ ] Confirm travel arrangements to Platinum Mall, Golf City, Lucknow.

### Milestone 1: Oct 30 — 07:30 PM
- [ ] Log in to Odoo portal and check the "Evaluator" card.
- [ ] Record evaluator's contact info, GitHub username, or communication channel.

### Milestone 2: Oct 31 — 08:30 AM
- [ ] Convene with team to read all released problem statements.
- [ ] Brainstorm feasibility, scope, and technical fit within 30 minutes.
- [ ] Formally lock in and submit chosen problem statement on the portal.

### Milestone 3: Oct 31 — 09:00 AM
- [ ] Initialize GitHub repository with standard `.gitignore`, `README.md`, and license.
- [ ] Submit GitHub repository link in the Odoo portal under "Submit Solution".
- [ ] Distribute branch permissions and kick off coding sprint.

### Milestone 4: Oct 31 — 10:00 AM
- [ ] Navigate to GitHub Repo > `Settings` > `Collaborators`.
- [ ] Send collaborator invitation to the assigned evaluator.
- [ ] Confirm invitation is sent before the 10:00 AM deadline.

### Milestone 5: Oct 31 — 05:00 PM (Code Freeze)
- [ ] Stop all new feature implementation by 04:30 PM to avoid breakages.
- [ ] Push final clean commit to main branch.
- [ ] Verify `README.md` includes setup steps, architecture overview, and feature breakdown.

### Milestone 6: Oct 31 — 05:30 PM (Final Video Submission)
- [ ] Record a 2–3 minute concise demonstration showcasing problem solved, core features, and tech stack.
- [ ] Upload video (YouTube Unlisted, Loom, or Google Drive with open view permissions).
- [ ] Paste final video URL into the submission field on the Odoo dashboard.
- [ ] Take screenshot of confirmed submission screen.
